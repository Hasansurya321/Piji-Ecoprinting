# IMPLEMENTATION RULE

==============================================================================

Pada setiap fase AI WAJIB:

1. Membaca requirement fase.

2. Mengimplementasikan hanya requirement pada fase tersebut.

3. Memastikan tidak ada error.

4. Memastikan kode bersih.

5. Melakukan self review.

6. Baru berpindah ke fase berikutnya.
